# The api-server artifact declares a database it never uses

**Type:** cleanup. **Needs the API?** No. **Size:** one file.

Read [`RAILS.md`](../../../RAILS.md) first, as always.

## What is there

`artifacts/api-server` came with the Replit template, in the initial commit. It
is not a second backend and nobody built one here — it serves exactly one route,
`/health`, plus the websocket that backs `infra-terminal.tsx`.

Its `package.json`, however, declares:

```
"drizzle-orm": ...,
"@workspace/db": ...
```

An ORM and a database package. **Neither is imported anywhere in `src/`**.
The database package resolves from `lib/db`; the issue is its unused dependency
in the terminal server, not workspace resolution.

## Why it is worth ten minutes

This repository's first rail is that no backend rule lives here; the core owns
the schema and every write goes through it. A dependency list is not a rule, so
nothing is broken today.

What is there is a loaded gun. On the afternoon somebody needs "just one quick
table", the place is already built, already named `api-server`, already has an
ORM in its manifest, and the pull request will look like configuration rather
than like an architectural decision. Removing two lines now costs nothing;
removing a schema later costs a migration and an argument.

## What to do

1. Delete `drizzle-orm` and `@workspace/db` from
   `artifacts/api-server/package.json`.
2. Keep everything the terminal needs — `express`, `ws`, `node-pty`, `pino`,
   `cookie-parser`, `cors`. `infra-terminal.tsx` is mounted in
   `workspace-cockpit.tsx` and connects to `/api/terminal`; it is live, and this
   change must not touch it.
3. `pnpm install` to update the lockfile, then build the artifact and open the
   terminal screen once to confirm it still connects.

## Done means

- [ ] No ORM and no database package in `artifacts/api-server/package.json`.
- [ ] `pnpm-lock.yaml` regenerated by the install, not edited by hand.
- [ ] The artifact builds.
- [ ] The terminal in the workspace cockpit still opens and echoes input.
